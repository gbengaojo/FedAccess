# FedAccess

## Purpose
This repository is meant to assist in acquiring Federal Contracts through SAM.gov
and affiliate entities. In addition, it is meant to assist in small businesses, 
and in particular SBA assistance when available.

###
A High priority is given to women and minority owned businesses. This is in
accordance with the tenets of SBA in general. Large corporations are welcome as
desired.

### Chronicle
This chronicles my journey through navigating the Federal Access and Bidding
Systems, as of aprroximately year 2020. Things have changed and are doing so
rapidly, so any outdated information and pull requests are welcome.
